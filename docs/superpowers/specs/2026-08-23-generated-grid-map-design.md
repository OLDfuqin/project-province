# 9×9 随机网格地图与中立地区设计

日期：2026-08-23
状态：已确认设计，等待实施计划

## 1. 目标与范围

本轮更新将当前32地区固定地图替换为一张物理尺寸为 `9×9` 的正方形网格地图。新游戏时由 C++ 模拟核心随机生成各单位格的地形、人口和初始经济，再合并四国首都，得到69个最终可操作地区。

本轮同时引入：

- 四国角落领土和中央无主地带；
- `2×2` 首都地区；
- 数据驱动的网格布局；
- 可注入随机源的 C++ 地图生成器；
- 可保存的地区基础经济；
- 隐藏中立势力、无主守军和直接征服；
- “首都”地形；
- 新地图专用存档版本。

本轮不实现玩家输入种子、地图编辑器、任意多边形地图、随机国家数量、动态地图尺寸选择或旧32地区存档迁移。

## 2. 架构方案

采用“C++运行时地图生成器 + 数据驱动布局”。

新增独立 `MapScenarioGenerator`：

- 读取网格布局配置和四个正常国家数据；
- 按明确顺序生成81个基础单元；
- 生成基础地貌、可见地形、人口和基础经济；
- 分配四国与无主地区；
- 合并四个首都；
- 创建隐藏中立势力及中立守军；
- 返回完整、已校验的 `GameState`。

生成器不依赖 Godot。正式游戏使用系统熵随机源；测试向生成器注入固定随机序列。

Godot 地图层读取与核心相同的网格布局定义，根据最终地区ID生成显示多边形。玩法数据只由 C++ 核心持有，Godot 不复制人口、地形、经济或归属公式。

## 3. 坐标系与物理网格

逻辑坐标左下角为 `(1,1)`，右上角为 `(9,9)`：

```text
y=9  □ □ □ □ □ □ □ □ □
 ...
y=1  □ □ □ □ □ □ □ □ □
     x=1             x=9
```

单位格边长为1，整张地图边长为9。只有共边的地区互为邻接；仅接触顶点不构成邻接。

Godot 屏幕坐标可将逻辑 `y` 轴翻转为向下显示，但地区ID、生成顺序和玩法坐标始终使用逻辑坐标。

## 4. 国家位置、城市、首都与无主地带

| 国家 | 国家ID | 初始单位格范围 | 首都原始四格 |
|---|---|---|---|
| 奥罗里亚 | `auroria` | `x=1..4, y=1..4` | `x=2..3, y=2..3` |
| 凯洛斯 | `caelus` | `x=6..9, y=1..4` | `x=7..8, y=2..3` |
| 索尔梅尔 | `solmere` | `x=1..4, y=6..9` | `x=2..3, y=7..8` |
| 维丹提亚 | `verdantia` | `x=6..9, y=6..9` | `x=7..8, y=7..8` |

满足 `x=5` 或 `y=5` 的单位格为无主地块，共：

```text
9 + 9 - 1 = 17格
```

每个国家的 `4×4` 范围先生成16个普通单位格，再把中央 `2×2` 四格合并为一个首都。剩余12个单位格为该国城市。

最终地区数量：

```text
4 × (1首都 + 12城市) + 17无主地区 = 69地区
```

首都邻接表取合并前四格对外共边邻格的并集，删除首都内部四格之间的边，并按稳定地区ID排序去重。

## 5. 地区ID与显示名称

普通单位格稳定ID使用：

```text
cell_<x>_<y>
```

例如：

- `cell_1_1`：`奥罗里亚城市(1,1)`；
- `cell_5_1`：`无主地块(5,1)`。

首都稳定ID使用：

- `capital_auroria`：`奥罗里亚首都`；
- `capital_caelus`：`凯洛斯首都`；
- `capital_solmere`：`索尔梅尔首都`；
- `capital_verdantia`：`维丹提亚首都`。

正式地名以后可通过布局数据替换，稳定ID不随显示名称变化。

## 6. 蛇形生成顺序

81个单位格按行进行蛇形遍历：

```text
第1行：(1,1) → (2,1) → ... → (9,1)
第2行：(9,2) → (8,2) → ... → (1,2)
第3行：(1,3) → (2,3) → ... → (9,3)
……
第9行：(1,9) → (2,9) → ... → (9,9)
```

生成某格时，只读取已经生成且与该格共边的邻格。根据蛇形顺序，除 `(1,1)` 外通常存在一个或两个可用邻格。

## 7. 基础地貌与森林覆盖

生成阶段区分：

- **基础地貌**：平原、丘陵、山地；
- **可见地形**：平原、丘陵、山地、森林。

`(1,1)` 的基础地貌和可见地形固定为平原。

### 7.1 单邻格传播概率

| 已生成邻格的基础地貌 | 新格为平原 | 新格为丘陵 | 新格为山地 |
|---|---:|---:|---:|
| 平原 | 50% | 50% | 0% |
| 丘陵 | 40% | 30% | 30% |
| 山地 | 0% | 50% | 50% |

### 7.2 双邻格平均

若有两个已生成邻格，分别取得其三项概率并逐项算术平均：

```text
最终概率(地貌) = (邻格A概率 + 邻格B概率) / 2
```

例如平原邻格与山地邻格共同影响：

```text
平原25%、丘陵50%、山地25%
```

所有原始概率为10%的整数倍，双邻格平均后为5%的整数倍，可用整数权重精确抽样，不使用浮点比较。

### 7.3 森林覆盖

基础地貌为丘陵或山地时，再独立进行一次等概率判定：

```text
50%保持原可见地形
50%变为可见森林
```

森林影响后续格生成时，仍使用其生成时保存的基础丘陵或基础山地传播概率。基础地貌只存在于本次地图生成的临时数据中，不进入正式游戏状态或存档。

## 8. 初始人口生成

可见地形确定后，从对应四个整数中等概率选择一个：

| 可见地形 | 可选初始总人口 | 单个值概率 |
|---|---|---:|
| 山地 | 30000、40000、50000、60000 | 25% |
| 丘陵 | 50000、60000、70000、80000 | 25% |
| 森林 | 70000、80000、90000、100000 | 25% |
| 平原 | 90000、100000、110000、120000 | 25% |

普通国家单位格初始可招募人口：

```text
floor(初始总人口 / 100)
```

当前人口均为万的整数倍，因此该取整不会产生歧义。

## 9. 首都合并与首都地形

完成81格的地形、人口和基础经济生成后，再合并四国中央四格。

首都初始状态：

```text
总人口 = 四格总人口之和
可招募人口 = 四格可招募人口之和
基础经济 = 四格基础经济之和
人口增长余数 = 四格余数之和后按人口增长分母归一化
地形 = 首都
```

新游戏生成时四格人口增长余数均为0，因此当前首都初始余数也是0；归一化规则用于保持接口完整。

“首都”新增为正式 `TerrainType`，参数如下：

| 参数 | 首都规则 |
|---|---|
| 无道路移动成本 | 与平原相同 |
| 地形经济系数 | `T=1.0`，与平原相同 |
| 道路端点基础费用 | 与平原相同，300 |
| 道路科技最低门槛 | 与平原相同 |
| 地形防守加成 | 50% |

首都面积为 `2×2`，但仍是一个地区和一个移动节点。进入或离开首都只发生一次地区移动。

## 10. 地区基础经济

### 10.1 新状态字段

`Province` 新增持久化字段：

```text
base_economy: int64
```

普通单位格初始基础经济：

```text
基础经济 B = floor(初始人口 P × 当前地形经济系数 T)
```

地形经济系数保持：

| 地形 | T |
|---|---:|
| 平原 | 1.0 |
| 首都 | 1.0 |
| 森林 | 0.9 |
| 丘陵 | 0.9 |
| 山地 | 0.8 |

首都合并时不重新按首都 `T=1.0` 计算，而是严格相加原四格基础经济。

### 10.2 经济科技与财政收入

设实际控制国经济科技等级为 `L`：

```text
地区经济 E = floor(B × (100 + 10×L) / 100)
地区财政收入 F = floor(E / 100)
```

经济科技只改变地区经济；财政收入仍固定只由最终经济的1%派生。

占领区继续暂用实际控制国的经济科技等级，保持当前已标记为待后续解决的口径。

### 10.3 人口变化同步基础经济

对任意正常归属地区，人口发生正负变化时：

```text
人口增加N：B' = B + floor(N×T)
人口减少N：B' = max(0, B - floor(N×T))
```

人口增长和征兵均必须通过共享的人口—经济调整接口执行，避免只修改人口而漏改基础经济。首都使用 `T=1.0`。

人口变化只按变化发生时的当前可见地形系数计算，不追溯重算全部历史人口经济。

## 11. 隐藏中立势力

为适配现有军队必须拥有 `CountryId` 的核心模型，内部增加隐藏中立势力，例如稳定ID `neutral`。

它不属于第五个正常国家：

- 不出现在玩家国家列表、国家统计、外交目标或胜负判断中；
- 没有玩家或AI控制入口；
- 不研究科技、不修路、不招募、不宣战、不议和；
- 不产生可计入国家国库的财政收入；
- 不生成主动移动或自动推进计划；
- 与四个正常国家在移动和战斗合法性上永久敌对。

中立军队只在自己的无主地块防守，永不主动进入其他地区。

## 12. 无主地块初始状态

每个无主地块保留正常随机生成的人口、可见地形和基础经济，但使用特殊结算规则：

```text
初始中立守军兵力 = floor(初始总人口 / 100)
可招募人口 = 0
财政收入 = 0
```

每个仍然无主的地块最多存在一支中立军队。开局为17个无主地块分别创建17支守军。

基础经济在无主期间保留但不产生财政收入；地区被正常国家取得后即可按正常规则使用这份基础经济。

## 13. 无主地块每月人口与守军增长

仍按现有总人口基础月增长率0.1%计算增长量和余数。设：

- 月初总人口为 `P`；
- 上月余数为 `r`；
- 分母为10000；
- 增长率分子为10。

```text
增长分子 = P×10 + r
本月增长 G = floor(增长分子 / 10000)
新余数 r' = 增长分子 mod 10000
```

对仍然无主的地块：

- 总人口保持 `P`，不增加 `G`；
- 基础经济不因这次增长改变；
- 可招募人口保持0；
- `G` 全部加入该地唯一中立守军；
- 若守军不存在且 `G>0`，则重新创建一支兵力为 `G` 的守军；
- 更新人口增长余数为 `r'`。

当前无主地块最低人口为30000，因此月增长至少为30，守军缺失时下月必然能够重建。

一次推进3、6或12个月时仍逐月结算，守军逐月增长。

## 14. 永久敌对、被动防守与直接征服

正常国家军队可以直接进入无主地块，无需宣战。移动系统把隐藏中立势力视为永久敌对，进入后按正常战斗系统结算地形、随机参数、军事科技和伤亡。

中立军事科技固定为0级。中立势力不获得AI行动，因此不会主动进攻。

若中立守军仍存活，按现有“防守方死战不退”规则阻止占领。若守军全部被消灭且正常国家进攻军存活：

1. 无主地块法理所有者立即改为进攻国；
2. 实际控制者同时成为进攻国；
3. 不创建普通战争占领记录；
4. 不进入宣战、战争、和平谈判或吞并流程；
5. 清除该地区的“无主”特殊状态；
6. 地区从下月开始恢复正常人口增长、可招募人口增长、基础经济随人口变化和财政收入；
7. 玩家军队留在目标地区。

中立守军被消灭但进攻方也归零时，地区保持无主；下月按无主规则重建守军。

“每个地块只能有一支部队”的限制只适用于仍然无主时的中立守军。地区归属正常国家后，恢复普通多军队驻扎规则。

## 15. 国家经济、世界统计与界面

- 四个正常国家开局各控制13个地区；
- 隐藏中立势力不进入四国国家摘要；
- 无主地块财政收入始终为0；
- 世界总人口应包含69个最终地区，包括无主地块；
- 世界军队/士兵统计包含中立守军，但界面应明确标识其为中立守军；
- 无主地区地图颜色使用统一中性色；
- 首都显示为 `2×2` 大地区并显示“首都”地形；
- 地区信息窗口显示坐标名称、归属状态、人口、基础经济派生出的经济、财政收入和守军；
- 外交目标、国家列表和科技窗口不得显示隐藏中立势力。

## 16. 布局数据与地图绘制

新增版本化网格布局数据，至少描述：

- 宽度9、高度9；
- 逻辑坐标范围；
- 蛇形遍历方式；
- 四个国家的矩形范围；
- 四个首都合并组；
- 无主判定；
- 单位格显示尺寸或归一化几何参数。

核心和Godot均以该布局数据为输入。核心产生最终地区ID、邻接与状态；Godot根据相同的单元和合并组产生最终69个多边形。两边均应验证最终ID集合一致。

地图绘制数据不保存人口、地形、经济或军队，避免形成第二套玩法状态。

## 17. 新游戏、随机源与读取存档

每次调用“开始新游戏”时：

1. 创建新的系统随机源；
2. 重新生成81格随机地形和人口；
3. 合并首都；
4. 创建四国、隐藏中立势力和守军；
5. 返回69地区完整状态。

地图随机种子和生成器状态不保存。保存游戏时直接保存生成后的正式结果，因此读取存档不会重新生成或改变地图。

测试使用显式可注入随机序列，验证边界概率、生成顺序和合并结果，不依赖系统随机结果。

## 18. 存档与旧版本兼容

存档版本升级。新存档至少新增或改变：

- 69地区的随机人口和可见地形；
- `base_economy`；
- 首都地形；
- 新地区ID和邻接；
- 无主/正常归属状态；
- 中立守军和隐藏中立势力；
- 新地图布局版本标识。

新版本明确拒绝旧32地区存档，不进行自动迁移。旧存档可继续由旧版本游戏读取。

新版本读取时必须验证存档地图布局版本与当前布局兼容，不能把69地区状态加载到其他几何地图。

## 19. 错误处理与不变量

生成或加载失败时不得产生部分地图。至少验证：

- 布局恰有81个唯一坐标；
- 坐标范围为1至9；
- 四国范围不重叠；
- 无主格恰为17；
- 每个首都组恰有4个共边组成 `2×2` 的格子；
- 每国最终恰有13个地区；
- 最终地区总数为69；
- 所有邻接对称、无自身邻接、目标ID存在；
- 四个首都地形正确；
- 每个无主地区最多一支中立守军；
- 隐藏中立势力没有AI、外交或财政入口；
- 所有人口、基础经济、可招募人口和军队兵力非负；
- 地图显示ID集合与核心地区ID集合一致。

随机回调返回越界值、布局配置不合法、人口或经济加和溢出时抛出明确错误并放弃整个新游戏创建。

## 20. 验收测试

### 20.1 生成器核心测试

- 蛇形81格顺序准确；
- `(1,1)`固定平原；
- 单邻格三套传播概率边界；
- 双邻格逐项平均；
- 丘陵/山地50%森林覆盖边界；
- 森林继续使用原基础地貌传播；
- 四类人口各四个离散值及边界；
- 固定随机序列得到固定完整地图；
- 非法随机值和非法布局整体失败。

### 20.2 地区与首都测试

- 物理单元81、最终地区69；
- 四国各13、无主17；
- 四个首都坐标和ID正确；
- 首都人口、可招募人口、基础经济严格求和；
- 首都邻接正确且对称；
- 首都移动、经济、道路参数等同平原；
- 首都防守加成50%。

### 20.3 经济与人口测试

- 普通地区初始基础经济按人口和T计算；
- 首都基础经济使用四格之和而非重新计算；
- 经济科技只乘算基础经济；
- 财政收入为最终经济1%；
- 正常人口增长同步增加基础经济；
- 征兵同步减少人口与基础经济；
- 无主地块财政为0且人口不增加。

### 20.4 中立地区测试

- 17个无主地区各有且只有一支初始守军；
- 初始守军为人口1%，可招募人口0；
- 月增长全部进入守军并正确累计人口增长余数；
- 守军缺失时下月重建；
- 中立军不移动、不主动攻击、不研究、不外交；
- 正常国家无需宣战即可攻击；
- 守军存活则原地防守；
- 征服后立即转移法理归属，不建立战争占领；
- 双方同归于尽时保持无主；
- 征服后恢复正常地区规则。

### 20.5 桥接、界面与完整回归

- Godot地图显示69个最终地区和正确大小的四个首都；
- 地图ID集合与核心摘要一致；
