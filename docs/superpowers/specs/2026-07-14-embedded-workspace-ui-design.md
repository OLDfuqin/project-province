# 主窗口内嵌多窗口界面设计

## 目标

在不创建 Windows 原生子窗口的前提下，在 Godot 主窗口内预留一个固定的工作区。
地区信息、地区管理和道路建设都显示在该工作区中，不覆盖地图，也不挤占下一回合按钮。

本阶段保留现有宣战、和平、科技、存档、回合和其他全局操作。现有英文文本暂不批量翻译；新增窗口使用中文标签。

## 主界面布局

主窗口分为三个稳定区域：

1. 顶部回合栏：日期、回合长度和进入下一回合。
2. 主体地图与全局控制区：地图保持可点击；现有全局按钮继续可用。
3. 内嵌窗口工作区：固定留白区域，同一时间最多显示一个业务窗口。

工作区没有活动窗口时显示空白占位提示，不让任何窗口覆盖地图输入区域。

## 界面状态

工作区状态：

- `closed`：无活动窗口。
- `province_info`：地区信息窗口。
- `province_management`：地区管理窗口。
- `road_construction`：道路建设窗口。

地图输入状态：

- `normal`：普通浏览。
- `army_destination`：为选中的军队选择目的地。
- `road_start`：选择道路起点。
- `road_end`：选择道路终点。

地图输入状态优先于普通地区点击。道路选择期间，点击地区不会打开信息或管理窗口。

## 地区点击交互

### 单击

普通状态下单击地区，在工作区显示地区信息窗口，内容包括：

- 地区名称、地形、法理归属和实际控制者。
- 总人口、可招募士兵、经济值。
- 驻扎军队数量与总兵力。
- 邻接地区数量和相关道路。

点击空白地图或执行无关的全局操作时自动关闭。

### 双击

普通状态下双击地区，用地区管理窗口替换信息窗口。管理窗口首版包含：

- 招募 1000 人陆军。
- 查看该地区驻军。
- 选择驻军并进入目的地选择状态。
- 经济投资占位模块，暂不可用。
- 民生投资占位模块，暂不可用。
- 建筑管理占位模块，暂不可用。
- 返回或关闭按钮。

地区管理内部的招募、军队选择和目的地选择不会自动关闭管理窗口；执行其他全局操作时关闭。

## 道路建设窗口

主页面删除原有的内联道路选择控件，只保留“修建道路”入口按钮。点击后在工作区打开道路建设窗口。

道路窗口包含：

- 选择起点。
- 选择终点。
- 确认修建。
- 重置选择。
- 返回主页面。
- 起点、终点、预计费用与状态/错误提示。

交互流程：

1. 点击“选择起点”后进入 `road_start` 状态。
2. 点击玩家实际控制的地区，将其设为起点。
3. 点击“选择终点”后进入 `road_end` 状态。
4. 合法终点必须由玩家控制、与起点相邻、尚无道路且不能与起点相同。
5. 点击“确认修建”调用现有 C++ 道路命令；资金与最终合法性仍由模拟核心裁定。
6. 修建成功后自动清空起点、终点和地图选择状态，但道路窗口保持打开，允许继续修路。
7. “重置选择”可随时清空起点、终点和选择状态。

现有道路规则不变：两个端点必须相邻、都由付款国家实际控制、连接上没有公路且国家资金足够。

## 自动关闭规则

以下操作会关闭当前地区信息或地区管理窗口：

- 点击空白地图。
- 打开道路建设窗口。
- 推进回合。
- 宣战、和平、科技、快速存档或读取等无关全局操作。

道路建设和军队目的地选择属于持续操作，相关地图点击不会关闭其所属窗口。

## 扩展接口

地区管理窗口以独立场景实现，后续增加经济投资、民生投资和建筑系统时只扩展该场景及对应桥接命令，不重新修改地图点击协议。

## 本阶段不做

- 不实现经济投资数值规则。
- 不实现民生投资数值规则。
- 不实现建筑数据和建造规则。
- 不批量翻译现有英文界面。
- 不创建操作系统级独立窗口。

## 验收标准

- 地图、顶部回合栏、全局控制区和工作区互不重叠。
- 单击与双击地区分别打开正确窗口。
- 无关操作会自动关闭当前窗口。
- 地区管理可以完成现有征兵和军队调动。
- 道路起点和终点只能在对应选择状态下设置。
- 非法地区不会污染现有选择，并显示明确原因。
- 修路成功自动重置，手动重置按钮也有效。
- 现有全部核心和 Godot 冒烟测试继续通过。
