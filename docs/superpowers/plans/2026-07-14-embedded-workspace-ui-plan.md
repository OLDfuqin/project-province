# 主窗口内嵌多窗口界面实施计划

## 总体策略

在隔离工作树和功能分支中实施，避免覆盖主工作区里的 Godot 编辑器元数据。每个任务单独测试和提交，完成后再合并回 `main`。

| 任务 | 主要内容 | 主要验证 | 预计投入 |
| --- | --- | --- | --- |
| 0 | 创建 `feature/embedded-workspace-ui` 工作树，验证当前基线 | SCons、核心测试、现有 Godot 测试 | 0.5 小时 |
| 1 | 拆分地图普通单击、双击和选择模式事件 | 地图输入测试；重复点击同一地区仍可触发 | 2 小时 |
| 2 | 重构主场景，加入固定工作区和窗口管理状态机 | 布局无重叠；其他主页面按钮仍存在 | 3 小时 |
| 3 | 实现地区信息窗口和自动关闭规则 | 单击、空白点击、全局操作关闭测试 | 2 小时 |
| 4 | 实现地区管理窗口、征兵、驻军列表和移动选点 | 招募与移动桥接测试；占位模块存在 | 4 小时 |
| 5 | 实现独立道路建设窗口和起终点选择状态 | 合法/非法端点、自动重置、手动重置测试 | 4 小时 |
| 6 | 完整回归、界面试玩和合并 | 核心测试、全部 Godot 测试、主场景启动 | 2 小时 |

预计总投入：约 17.5 小时。

## Task 0：隔离工作区与基线

- 从当前 `main` 创建 `feature/embedded-workspace-ui`。
- 初始化本地 `godot-cpp` 子模块依赖。
- 验证构建、核心测试、布局测试和主场景启动。
- 不提交主工作区现有的 `project.godot`、场景 UID、脚本格式化或日志文件。

## Task 1：地图输入协议

修改 `province_map.gd`，让地图可以区分：

- 普通单击地区。
- 双击地区。
- 点击空白区域。

事件必须在重复点击同一地区时继续触发，不能再以“选中 ID 是否变化”作为是否发送信号的条件。

保留现有选中高亮，并增加输入测试，验证双击不会被当作道路或军队选择。

建议提交：`feat: distinguish province click interactions`

## Task 2：主场景工作区与窗口管理器

- 将主场景改为响应式容器布局。
- 保持顶部回合栏独立。
- 保持地图和现有全局控制按钮可用。
- 删除原有内联道路控件，添加“修建道路”入口。
- 新增固定 `WorkspaceHost`。
- 实现工作区状态和地图输入状态，保证同一时间只有一个业务窗口可见。
- 扩展布局测试，验证地图、回合栏、全局控件和工作区无交叉。

建议提交：`feat: add embedded workspace shell`

## Task 3：地区信息窗口

新增独立的地区信息场景和脚本：

- 接收地区、道路和军队快照。
- 显示人口、可招募士兵、经济、地形、所有权、驻军和道路信息。
- 单击地区时刷新并打开。
- 点击空白或执行无关全局操作时关闭。
- 双击地区时由管理窗口替换。

建议提交：`feat: add province information window`

## Task 4：地区管理窗口

新增可扩展的地区管理场景：

- 复用现有征兵桥接命令。
- 过滤并显示当前地区的军队。
- 选择军队后进入目的地选择状态，并复用现有移动命令。
- 显示经济投资、民生投资和建筑管理占位区，但按钮禁用。
- 操作完成后刷新地区、国家、军队和地图数据。
- 保留现有其他全局按钮，不进行整套中文化。

建议提交：`feat: add province management window`

## Task 5：道路建设窗口

- 新增道路建设场景和脚本。
- 实现 `idle`、`selecting_start`、`selecting_end` 三种页面状态。
- 地图点击仅在对应状态下写入起点或终点。
- 起点必须由玩家实际控制。
- 终点必须由玩家控制、与起点相邻、不同于起点且尚无公路。
- 如界面需要邻接 ID，在桥接地区摘要中新增 `neighbor_ids`，不改变核心道路规则。
- 确认后调用现有 `build_road`；失败保留选择并显示原因，成功自动重置。
- 手动重置与返回按钮都清除道路选择和地图高亮。

建议提交：`feat: add dedicated road construction window`

## Task 6：最终回归与合并

- 运行 SCons/MSVC C++20 构建和核心测试。
- 顺序运行现有全部 Godot 冒烟测试以及新增界面测试。
- 以主场景启动两帧，检查脚本与 GDExtension 错误。
- 可视化启动游戏，手动检查单击、双击、征兵、移动和修路流程。
- 快进或无冲突合并回 `main`，保留主工作区未提交的 Godot 编辑器文件。

建议提交：`test: cover embedded workspace flows`
