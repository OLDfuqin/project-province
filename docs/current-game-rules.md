- 初始日期：1000年01月；
- 国家数：4；
- 地区数：32；
- 玩家国家固定为奥罗里亚（`auroria`）；
- 其余三个国家由 AI 控制；
- 所有国家初始科技均为0级；
- 初始无军队、道路、战争和占领状态；
- 每个国家初始国库都是10000。

### 剧本数据校验

剧本 JSON 的 `schema_version` 必须严格等于3。加载时还会检查：

- 国家名称非空、初始国库非负、颜色使用 `#RRGGBB`、国家 ID 不重复；
- 地区名称非空，总人口和可招募士兵非负；
- 可招募士兵不超过总人口；
- 地区 ID 不重复，邻接列表无重复且不能包含自身；
- 法理所有者和邻接地区都必须存在；
- `A` 把 `B` 列为邻接时，`B` 也必须把 `A` 列为邻接。

任一校验失败都会使整个剧本加载失败，不会加载部分地图。

## 核心数据、单位与稳定 ID

### 数值单位

| 数据 | 类型 | 单位与规则 |
|---|---|---|
| 国库 | 有符号64位整数 | 货币单位，不使用小数 |
| 总人口 | 有符号64位整数 | 人 |
| 可招募士兵 | 有符号64位整数 | 人 |
| 地区经济 | 有符号64位整数 | 由人口和经济科技实时计算，不保存 |
| 地区财政收入 | 有符号64位整数 | 每月进入实际控制国国库的货币 |
| 军队兵力 | 有符号64位整数 | 人 |
| 移动点 | 有符号32位整数 | 点，可跨回合累计 |
| 日期 | 整数 | 年、月；每年12个月 |
| 科技等级 | 有符号32位整数 | 0至3级 |

核心计算全部使用整数。除非本手册另有说明，整数除法产生的小数部分直接舍弃，即对非负数向下取整。

### 稳定 ID

国家、地区和军队都使用稳定 ID。合法字符只有：

- 小写英文字母 `a-z`；
- 数字 `0-9`；
- 下划线 `_`；
- 连字符 `-`。

ID 不能为空。当前军队内部 ID 按创建顺序生成：`army_1`、`army_2`、……。序号会写入存档，读取后继续递增。内部 ID 不向玩家开放修改。

每个国家另有一个唯一单字代号，每支军队另有一个本国编制编号 `X`。玩家看到的名称为：

```text
国家代号·第X军
```

例如 `奥·第1军`。编制编号只要求在同国现存军队中唯一，不同国家都可以存在第1军。

### 核心状态

游戏状态包含：

- 当前日期；
- 国家、国家代号和国库；
- 国家科技；
- 地区、法理归属、人口、邻接和地形；
- 道路；
- 军队、编制编号、兵力、位置、移动点和推进计划；
- 地区占领者；
- 国家战争关系；
- 下一个军队序号。

国家和地区等容器按稳定 ID 排序。部分“第一个合法目标”的选择因此采用 ID 字典序，详见 AI、撤退和议和章节。

### 桥接层与界面显示口径

Godot 地区摘要中的字段名称有一个需要特别注意的现行约定：

- `owner_id` 返回实际控制者；
- `legal_owner_id` 返回法理所有者；
- `occupied` 表示两者是否不同。

国家摘要的“地区数”也是实际控制地区数，并显示该国受控地区的经济总量与财政收入总和。主界面顶部“总人口”和“可招募士兵”是全世界32个地区的合计，不只是玩家国家；回合日志中显示的“财政收入”也是该回合所有国家财政收入之和。

### 命令状态与事件序号

核心命令通过临时状态执行，普通命令被拒绝时不会提交国库、人口、军队、道路、科技或外交变化。每个成功产生的游戏事件使用从1开始递增的事件序号，序号与游戏状态一起保存。

桥接层的“立即自动推进”由多个核心移动命令组成，不是单个原子核心命令；其部分成功、目标保留等特殊行为见自动推进章节。

## 回合、日期与月度结算顺序

### 合法回合长度

一次回合只能推进：

- 1个月；
- 3个月；
- 6个月；
- 12个月。

其他数值会被核心拒绝。界面默认选择1个月。

日期内部表示为从0开始累计的月份：

```text
累计月份 = 年份 × 12 + (月份 - 1)
年份 = 累计月份 ÷ 12
月份 = 累计月份 mod 12 + 1
```

例如1000年12月推进1个月后变为1001年01月。

### 多月回合

3、6或12个月不是一次性乘法结算，而是逐月完整执行。每个月都会使用上个月已经变化后的国库、人口、科技、控制权、军队和战争状态。

每个月严格按以下顺序执行：

1. 结算所有地区财政收入；
2. 结算所有地区总人口增长；
3. 结算所有地区可招募士兵增长；
4. 给当时已经存在的所有军队增加移动点；
5. 执行所有已启用的军队推进计划；
6. AI 根据此时状态生成当月决策；
7. 按顺序执行 AI 决策；
8. 日期增加1个月。

由此产生的关键结果：

- 当月经济科技研究发生在财政结算之后，所以从下个月开始提高经济与财政收入；
- 当月道路科技研究发生在移动点发放之后，所以从下个月开始提高每月移动点；
- AI 当月新招募的军队错过了当月移动点发放，初始移动点为0；
- 推进计划先于 AI 行动，玩家军队可以在 AI 决策前改变战线；
- 在一个12个月回合内，AI 会执行12轮月度决策，不是只行动一次。

## 地区法理归属、控制与占领

每个地区同时存在两个概念：

- **法理归属** `owner_id`：地区的正式所有者；
- **实际控制者**：若地区未被占领，则等于法理所有者；若被占领，则等于占领国。

经济科技口径、财政收入归属、征兵权限、修路权限、领土通行、国家存续和胜负判断都使用实际控制者，而不是法理归属。

占领不会立即改变法理归属。只有选择“吞并占领地区”的和平结算才会转移法理归属。

### 占领规则

- 与地区控制者处于战争状态的军队进入该地区后触发战斗检查；
- 若没有敌方守军，地区立即被进攻方占领；
- 若有守军，只有进攻方胜利且进攻军队仍存在时才占领；
- 原法理所有者重新控制自己的地区时，占领记录被删除；
- 占领不直接改变地区人口、可招募士兵或道路；经济是派生值，不是可被直接修改的地区状态。

## 总人口与可招募士兵

### 总人口月增长

总人口基础月增长率为0.1%，即万分之10。

系统保存一个 `population_growth_remainder`，用于累计不足1人的小数部分。设：

- 月初总人口为 `P`；
- 上月余数为 `r`，范围为0至9999；
- 分母为10000；
- 增长率分子为10。

则概念公式为：

```text
增长分子 = P × 10 + r
本月人口增长 G = floor(增长分子 / 10000)
新余数 r' = 增长分子 mod 10000
月增长后总人口 P' = P + G
```

实现使用拆分计算避免大整数乘法溢出，但结果与上式一致。

#### 示例：北境第一个月

```text
P = 120000，r = 0
G = floor(120000 × 10 / 10000) = 120
P' = 120120
r' = 0
```

### 可招募士兵月增长

可招募士兵在总人口增长之后结算，并使用增长后的总人口 `P'`。

```text
候选增加量 C = floor(P' × 0.5%)
人数上限 L = floor(P' × 10%)
剩余容量 A = max(0, L - 当前可招募士兵 R)
实际增加量 RG = min(C, A)
新可招募士兵 R' = R + RG
```

可招募士兵的0.5%小数部分不会跨月累计，每月独立向下取整。

#### 示例：北境第一个月

北境总人口先从120000增长到120120：

```text
C = floor(120120 × 0.005) = 600
L = floor(120120 × 0.10) = 12012
R = 2000
RG = min(600, 12012 - 2000) = 600
R' = 2600
```

连续结算3个月后，北境总人口为120360，可招募士兵为3802。

若可招募士兵已经等于或高于当月上限，系统只停止增长，不会主动把现有人数削减到上限。

### 征兵对人口的影响

招募 `M` 人军队时：

```text
地区总人口 -= M
地区可招募士兵 -= M
```

两项同时减少相同人数。人口增长余数不会因征兵重新计算或清零。

### 控制权与人口

所有地区无论是否被占领都会正常增长。增长率不受国家、控制权、战争、地形、经济或科技影响。

## 地区经济与国家国库

地区不再保存固定经济字段。经济由地区人口、经济科技与地形实时派生，财政收入固定为经济的1%。每月财政收入归当前实际控制者。

设地区总人口为 `P`，当前采用的经济科技等级为 `L`。地形经济系数 `T` 为：

| 地形 | T |
|---|---:|
| 平原 | 1.0 |
| 森林 | 0.9 |
| 丘陵 | 0.9 |
| 山地 | 0.8 |

地区经济对科技倍率与地形系数只进行一次最终向下取整：

```text
地区经济 E = floor(P × (100 + 10 × L) / 100 × T)
```

实现使用等价整数公式，避免浮点误差。令平原、森林、丘陵和山地的地形分子 `R` 分别为100、90、90、80：

```text
E = floor(P × (100 + 10 × L) × R / 10000)
地区财政收入 F = floor(E / 100)
```

财政收入计算不再直接读取地形系数，地形只通过经济间接影响财政收入。

国家经济总量等于其实际控制地区经济之和；国家月财政收入等于其实际控制地区财政收入之和。财政收入在每月开始时直接加入国库。取整在每个地区分别发生，然后再求和。

### 科技倍率

| 经济科技 | 经济倍率 |
|---:|---:|
| 0 | 100% |
| 1 | 110% |
| 2 | 120% |
| 3 | 130% |

#### 示例

北境为平原，人口120000，经济科技0级：

```text
经济 = floor(120000 × 100 × 100 / 10000) = 120000
财政收入 = floor(120000 / 100) = 1200
```

若经济科技升至1级，人口不变：

```text
经济 = floor(120000 × 110 × 100 / 10000) = 132000
财政收入 = floor(132000 / 100) = 1320
```

人口30000、经济科技0级的森林地区，经济为27000，财政收入为270。

奥罗里亚初始控制地区经济总量为362500，0级经济科技下月财政收入为3625，国库从10000变为13625。

> **优先待解决逻辑：占领区经济科技归属。** 当前实现临时使用地区“实际控制国”的经济科技计算占领区经济与财政收入。因此占领会立即切换科技倍率。该口径尚未完成最终设计，后续应优先决定改用法理所有国、地区自身经济状态、占领惩罚或其他规则；在决定前不修改当前实现。

当前没有税率、维护费、负收入、债务或经济投资。经济会随人口、经济科技和地形变化；财政收入只由经济派生，不拥有独立增长率，也不被经济科技或地形直接修改。

## 科技等级、费用与效果

每个国家创建时自动获得三条0级科技：

- 经济；
- 军事；
- 道路。

每条科技最高3级。当前 `game/data/technologies.json` 为空且不会被剧本加载器读取；科技状态由国家创建过程自动生成。

### 研究费用

从当前等级 `L` 提升到 `L + 1`：

```text
研究费用 = 1000 × (L + 1)
```

| 升级 | 费用 |
|---|---:|
| 0 → 1 | 1000 |
| 1 → 2 | 2000 |
| 2 → 3 | 3000 |

研究立即完成并立即扣款。以下情况拒绝研究且不改变状态：

- 国家不存在；
- 科技已达到3级；
- 国库不足；
- 桥接层收到的科技轨道不是 `economy`、`military` 或 `roads`。

### 科技效果

| 科技 | 每级效果 |
|---|---|
| 经济 | 地区经济每级增加10%；财政收入只通过经济间接受影响 |
| 军事 | 本国军队战斗有效战力增加10% |
| 道路 | 每月每支军队增加1点额外移动点；修路费用降低100 |

道路科技不改变已有公路的单次移动成本，公路移动成本始终为1。

## 道路建设

当前只有两种道路等级：

- 无道路 `none`；
- 公路 `paved`。

道路属于两个地区之间的无方向连接，`A—B` 与 `B—A` 是同一条路。

### 建设条件

修建公路必须同时满足：

1. 付款国家存在；
2. 两个端点地区都存在且不是同一地区；
3. 两个地区逻辑相邻；
4. 两个地区当前都由付款国家实际控制；
5. 该连接尚无公路；
6. 国库足以支付费用。

建设立即完成，没有施工时间。占领地区只要由付款国家实际控制，也能作为修路端点。

### 建设费用

设道路科技等级为 `L`：

```text
公路费用 = 500 - 100 × L
```

| 道路科技 | 费用 |
|---:|---:|
| 0 | 500 |
| 1 | 400 |
| 2 | 300 |
| 3 | 200 |

## 军队招募

核心和当前界面都支持招募任意正整数兵力。玩家在地区管理窗口打开招募区，输入人数后确认；界面显示地区可招募士兵、国家国库和两者共同限制的最大可招募人数。

### 招募费用

```text
招募费用 = 招募人数 × 1
```

即每名士兵消耗1国库。

### 招募条件

招募必须满足：

1. 招募人数大于0；
2. 国家和地区存在；
3. 地区当前由招募国家实际控制；
4. 地区可招募士兵不少于招募人数；
5. 地区总人口不少于招募人数；
6. 国家国库不少于招募费用。

成功后：

- 扣除国库；
- 同量扣除总人口和可招募士兵；
- 创建一支独立陆军；
- 新军队位于招募地区；
- 新军队初始移动点为0；
- 新军队取得所属国当前未使用的最小正整数编制编号；
- 新军队没有推进目标，推进状态默认启用，默认策略为最大推进。

军队被消灭或因合并删除后，其编制编号立即释放。后续招募会从1开始重新寻找最小空缺编号。

### 军队更名

玩家可在地区管理窗口输入新的正整数 `X`。更名只改变编制编号，不改变内部军队 ID、位置、兵力、移动点或推进计划。新编号不得与同国另一支现存军队重复；跨国同号合法。改成当前编号属于成功的幂等操作。

### 军队合并

一个地区可以驻扎多支同国或不同国家军队。玩家可以选择一支主军，并多选同地区、同国家的其他军队并入主军。

成功合并后：

- 保留主军内部 ID、编制编号、位置和完整推进计划；
- 主军兵力等于所有参与军队兵力之和；
- 主军移动点取所有参与军队中的最小值；
- 被并入军队删除，其编制编号释放。

主军不存在、没有被并入军队、列表重复、包含主军、军队不存在、异国、异地或兵力求和溢出时，整次合并失败，不产生部分修改。

当前没有拆分、组织度、补给、装备和军队维护费。AI 继续按固定批次招募，但当前不会主动更名或合并。

## 移动力、寻路与调动

### 每月移动点

设军队所属国道路科技等级为 `L`：

```text
每月获得移动点 = 2 + L
```

| 道路科技 | 每月移动点 |
|---:|---:|
| 0 | 2 |
| 1 | 3 |
| 2 | 4 |
| 3 | 5 |

移动点可以跨月、跨回合无限累计，当前没有上限。招募发生在当月移动点发放之后时，新军队要到下个月才能第一次获得移动点。

### 单步移动成本

军队一次基础移动只能从当前地区进入一个相邻地区。

```text
若两地之间有公路：成本 = 1
否则：成本 = 目的地地形成本
```

无道路时只看目的地地形，不看出发地地形。

### 通行条件

- 可以进入本国实际控制地区；
- 可以进入与军队所属国处于战争状态的国家所控制地区；
- 不能进入和平状态下的外国控制地区；
- 当前没有军事通行权系统。

移动点不足、目标不存在、目标不相邻或通行不合法时，移动被拒绝且军队不改变位置和移动点。

成功移动时先扣除移动点并更新位置，再检查战斗和占领。

### 寻路

自动寻路使用按移动成本计算的最短路径：

- 公路边成本1；
- 其他边成本等于进入目标地区的地形成本；
- 可以在本国控制地区中继续展开路径；
- 敌国地区可以作为路径终点，但不会从敌国地区继续展开；
- 和平外国地区完全不可通行。

因此，当前自动计划可以沿本国纵深到达前线或进入一个敌方边境地区，但不能规划一条连续穿过多个敌占地区的深远路线。

## 自动推进计划与策略

每支军队可以保存一个推进目标、启用状态和推进策略。设置新目标时：

- 目标必须是存在的地区；
- 不检查目标是否可达，也不检查目标是否就是军队当前位置；
- 推进计划自动启用；
- 策略重置为最大推进 `max`。

清除目标时，目标被删除且启用状态恢复为 `true`。只有存在目标时才能暂停、恢复或切换策略。

### 月度计划执行

每月发放移动点后，系统按军队 ID 顺序执行所有已启用计划。单支军队每月最多尝试“地区总数”次移动，当前剧本即最多32步，实际仍受移动点、路径和策略限制。

计划在以下情况停止当月推进：

- 找不到下一步路径；
- 移动点不足或移动命令被拒绝；
- 策略规定停止；
- 发生战斗；
- 发生地区占领；
- 军队被消灭；
- 已到达目标。

到达目标时自动清除推进目标。其他阻塞通常保留目标，下个月再次尝试。

若目标就是军队当前位置，设置操作仍会成功，但寻路没有下一步，月度计划会保留该目标并持续受阻。

### 三种策略

| 内部值 | 界面含义 | 行为 |
|---|---|---|
| `max` | 最大推进 | 当月尽可能沿路径连续移动，直到受阻 |
| `one_step` | 每回合一步 | 每个月最多移动一个相邻地区 |
| `stop_before_enemy` | 敌境前停止 | 下一步不是本国控制地区时立即停止，不进入敌境 |

这里的“一步”实际按月执行。在3个月回合中，`one_step` 最多执行3次单步移动，每个月一次。

### 立即自动推进

地区管理窗口的“立即自动推进”会立刻沿目标路径连续移动，直到移动点不足、无路、发生战斗/占领或军队被消灭，最多尝试地区总数次。

当前立即自动推进不读取军队的 `one_step` 或 `stop_before_enemy` 策略，按最大推进处理。若设置目标后没有成功移动，桥接调用会返回失败，但刚设置的目标可能仍保留在军队上。

## 宣战、战争状态与领土通行

国家关系当前只有和平与战争两种状态。没有显式关系记录时默认为和平。

### 宣战条件

宣战只要求：

1. 进攻国和防守国不是同一国家；
2. 两国都存在；
3. 两国当前没有处于战争状态。

宣战不要求接壤，不消耗国库，没有冷却、战争目标、稳定度或外交惩罚。国家可以同时参加多场战争。

宣战后双方军队可以进入对方实际控制地区。和平国家之间不能互相进驻。

### 战争概览统计

对每一场战争，界面按以下口径汇总：

- 双方兵力：该国所有现存军队的原始兵力之和；
- 占领地区：一方法理地区中由战争对手实际控制的数量；
- 战线数：双方实际控制地区之间、彼此相邻的地图连接数量。

地图上的战线高亮也使用“相邻地区控制者不同且双方正在交战”这一条件。

## 战斗、伤亡、撤退、歼灭与占领

军队进入一个存在敌对军队的地区时立即进行一次确定性战斗。当前没有随机数。

### 参战军队

- 进攻方只计算当前正在移动的那一支军队；
- 防守方计算目标地区内所有与进攻国交战的外国军队；
- 同地区其他进攻方军队不会加入本次进攻；
- 多支防守军队的战力相加。

### 有效战力

设军队兵力为 `M`，所属国军事科技等级为 `L`：

```text
军队有效战力 = floor(M × (100 + 10 × L) / 100)
```

防守方先分别计算每支军队有效战力并求和，再应用目标地区地形加成：

```text
防守总战力 = floor(防守军队有效战力之和 × (100 + 地形加成) / 100)
```

进攻方不获得地形加成。

### 胜负

```text
进攻方有效战力 > 防守总战力：进攻方胜利
进攻方有效战力 <= 防守总战力：防守方胜利
```

战力相等时防守方胜利。

### 伤亡

设防守总战力为 `DS`、进攻有效战力为 `AS`、进攻方原始兵力为 `AM`：

```text
进攻方伤亡 = min(AM, max(1, floor(DS / 4)))
防守方总伤亡预算 = max(1, floor(AS / 4))
```

防守伤亡预算按防守军队 ID 顺序分配。处理某支军队时：

```text
本军分配额 = max(1, floor(剩余预算 / 尚未处理的防守军队数))
本军实际伤亡 = min(本军兵力, 本军分配额)
剩余预算 -= 本军实际伤亡，最低为0
```

即使剩余预算已为0，后续每支防守军队仍至少分配1点，因此多支防守军队时实际总伤亡可能略高于初始预算。

#### 示例：平原1000人进攻500人

双方军事科技均为0，平原无防守加成：

```text
AS = 1000
DS = 500
进攻方胜利
进攻方伤亡 = floor(500 / 4) = 125，剩余875
防守方伤亡 = floor(1000 / 4) = 250，剩余250
```

### 失败、撤退和歼灭

- 进攻方失败且仍有兵力时，退回刚才的出发地区；
- 进攻方兵力降到0时被删除；
- 防守方失败时，依次寻找战斗地区的相邻地区；
- 合法撤退地必须由该防守军队所属国实际控制，并且不能是进攻军队的出发地区；
- 选择第一个符合条件的相邻地区；邻接表在加载时按地区 ID 排序；
- 没有合法撤退地时，防守军即使仍有兵力也会被全部删除；
- 防守方胜利时留在原地区。

### 无守军占领

若军队进入敌方控制地区但没有敌对守军：

- 不发生实际战斗；
- 没有伤亡；
- 地区立即被占领；
- 系统仍产生占领结果报告。

## 议和与领土结算

只有当前交战的两个不同国家能够议和。议和立即执行，不检查战争分数、战争时长、军力或 AI 同意。

### 恢复战前边界

对双方彼此占领的地区：

- 保留原法理归属；
- 删除占领记录；
- 实际控制恢复给法理所有者。

### 吞并占领地区

对双方彼此占领的地区：

- 将法理归属转移给当前占领国；
- 删除占领记录；
- 占领国成为新的法理所有者和实际控制者。

只处理这两个议和国之间形成的占领，不处理第三国占领。

### 境外军队遣返

领土结算并恢复和平后，系统遍历当前所有军队，而不只遍历两个议和国的军队：

1. 若军队所在地区由本国控制，则保持原位；
2. 否则将其瞬间移动到本国控制的第一个地区；
3. 目的地按地区 ID 字典序选择，不要求相邻且不消耗移动点；
4. 若本国没有任何控制地区，则删除该军队。

因此，当前实现中一次议和可能遣返与该和平协议无关、但正处于境外的第三国军队。这是现行核心行为。

## AI 月度决策

默认情况下，奥罗里亚是人类国家，其他三国每月由 AI 行动。AI 无随机性，相同状态会产生相同决策。

### 决策使用的军力

```text
国家军力 = 该国所有军队原始兵力之和
```

军力判断不使用军事科技、地形或位置。

AI 在生成当月全部决策前先拍摄一次状态快照。因此同月新招募的兵力不会影响该月的科技和宣战门槛，新宣告的战争也不会用于生成同月的移动决策。

### 决策顺序

每个 AI 国家依次考虑：

1. 招募；
2. 科技研究；
3. 宣战；
4. 为每支现有军队生成一次移动。

国家、地区和军队均按稳定 ID 顺序遍历。生成后再按这个顺序执行；执行时已经不合法的命令会被忽略。

### 招募决策

若：

- 国家军力低于1500；
- 国库至少500；
- 存在一个本国控制且可招募士兵不少于500的地区；

则在第一个符合条件的地区招募500人。每国每月最多生成一次招募命令。

### 科技决策

国家军力达到1500后，AI 选择等级最低的科技。等级相同时优先顺序为：

1. 经济；
2. 军事；
3. 道路。

未满3级且国库足够时研究一次。

### 宣战决策

国家军力达到1000后，AI 搜索一个与本国控制地区相邻的外国控制国。满足以下条件时宣战：

- 双方尚未交战；
- AI 国家军力大于或等于目标国军力。

每国每月最多生成一次宣战命令。AI 不评估科技、地形、国库、其他战争或外交后果。

### 移动决策

对每支 AI 军队：

- 寻找当前战争中按移动成本可达的最近敌方控制地区；
- 若存在路径且移动点足够，则移动一个相邻地区；
- 每支军队每月最多生成一次移动命令；
- 进入敌区后使用正常战斗与占领规则。

AI 当前不会主动修路、议和、设置长期推进计划或进行经济投资。

## 胜利、失败与国家存续

国家存续完全按实际控制地区数判断：

```text
控制地区数 = 0：国家被消灭
控制地区数 > 0：国家存续
```

法理领土和现存军队不阻止国家被判定消灭。

- 只剩一个存续国家时，该国成为胜利者，游戏结束；
- 玩家国家控制地区数为0时，玩家失败，游戏结束；
- 玩家是唯一存续国家时，玩家胜利。

当前 `game_over` 是状态判断与界面显示结果，模拟核心没有统一禁止游戏结束后继续提交命令。

## 保存与读取

当前界面提供一个快速存档槽：

```text
user://quick_save.json
```

Godot 会把它映射到当前用户的项目数据目录。

### 保存内容

结构版本4存档保存：

- 日期；
- 下一个事件序号；
- 人类玩家国家与 AI 是否启用；
- 下一个军队序号；
- 国家、国家代号、颜色和国库；
- 地区法理归属、人口、可招募士兵、邻接、人口增长余数和地形；
- 道路；
- 军队、编制编号、兵力、移动点、推进目标、启用状态和推进策略；
- 占领；
- 战争关系；
- 国家科技。

地图多边形、界面窗口状态、当前地图选择、事件历史文字不写入存档。

地区经济和财政收入都是派生值，不写入存档；读取后按人口、地形、控制权和科技重新计算。版本2及更早存档不兼容。版本3存档可以迁移到版本4。

保存前会验证状态。写入时先生成 `.tmp` 临时文件，再替换或重命名为正式存档。

### 读取规则

- 接受结构版本4和可迁移的版本3存档；
- 版本3缺少国家代号时按当前四国稳定 ID 补充；出现未知国家 ID 时拒绝迁移；
- 版本3缺少军队编制编号时，各国军队分别按内部 ID 字典序从1开始编号；
- 读取全部内容后验证引用、科技等级、军队状态、邻接和序号；
- 版本4要求国家代号非空且全局唯一，军队编号为正且同国唯一；
- 旧的同版本军队记录缺少 `advance_enabled` 时默认为 `true`；
- 缺少 `advance_strategy` 时默认为 `max`；
- 读取成功后恢复事件和军队序号，避免重复 ID；
- 读取失败时不会用半成品覆盖当前游戏状态。

## 当前规则边界与未定义行为

以下是理解当前规则时必须注意的边界，不代表尚未实现内容的设计承诺：

- 当前玩家国家固定为奥罗里亚，没有开局国家选择；
- 当前只有一种以人数表示的陆军；
- 战斗完全确定性，没有随机因素；
- 地区经济只由人口和经济科技派生，尚无投资、破坏或独立经济增长；
- 占领区暂用实际控制国经济科技，属于优先待定规则；
- 当前没有军队维护费、补给、士气、组织度和装备；
- 当前没有联盟、互不侵犯、军事通行、战争目标和战争分数；
- 当前没有税率、投资和建筑对数值的影响；
- 当前科技是三条0至3级的线性数值，不是数据驱动科技树；
- 当前没有战争迷雾，界面可读取全部国家和地区状态；
- 当前没有人口年龄、文化、宗教、教育、出生和死亡分项；
- 当前没有人口迁移；
- 对这些不存在的系统，其计算方式均为“当前未定义”。
